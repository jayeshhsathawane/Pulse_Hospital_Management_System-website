==========================================================
    PULSE HOSPITAL PROJECT - LIVE DEPLOYMENT STEPS
==========================================================

STEP 1: LOCAL PREPARATION (Apne Computer Par)
----------------------------------------------------------
1. Requirements file banayein (taaki server ko pata chale kya install karna hai):
   Command: pip freeze > requirements.txt

2. Migrations check karein:
   Command: python manage.py makemigrations

3. Settings.py Check:
   - DEBUG = False
   - ALLOWED_HOSTS = ['yourdomain.com', 'server_ip']
   - STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles')
   - MEDIA_ROOT = os.path.join(BASE_DIR, 'media')

STEP 2: SERVER SETUP (Code Upload ke Baad)
----------------------------------------------------------
1. Virtual Environment banayein aur activate karein:
   Command: python -m venv venv
   Command: source venv/bin/activate  (Linux) ya venv\Scripts\activate (Windows)

2. Zaroori libraries install karein:
   Command: pip install -r requirements.txt

STEP 3: DATABASE & ADMIN SETUP (Most Important)
----------------------------------------------------------
1. Database tables create karein:
   Command: python manage.py migrate

2. Fresh Admin ID banayein (Isse aap login kar payenge):
   Command: python manage.py createsuperuser
   (Username, Email aur Password enter karein)

STEP 4: STATIC FILES & PERMISSIONS
----------------------------------------------------------
1. Saari CSS/JS/Images ko ek jagah collect karein:
   Command: python manage.py collectstatic

2. Folder permissions set karein (Linux Servers ke liye):
   Command: chmod -R 755 static/
   Command: chmod -R 755 media/

STEP 5: SERVER RESTART
----------------------------------------------------------
1. Agar aap Gunicorn/Nginx use kar rahe hain:
   Command: sudo systemctl restart gunicorn
   Command: sudo systemctl restart nginx

            TROUBLESHOOTING (Common Errors)
==========================================================
- 500 Internal Server Error: Check DB Credentials in settings.py
- CSS/Design missing: Run 'collectstatic' again
- Image upload failing: Check 'media' folder permissions

==========================================================
    PULSE HOSPITAL - SETTINGS.PY LIVE CONFIGURATION
==========================================================

1. SECURITY SETTINGS (Sabse Zaroori)
----------------------------------------------------------
# Debug ko False karein taaki hackers ko error details na dikhein
DEBUG = False

# Sirf apne domain aur server IP ko allow karein
ALLOWED_HOSTS = ['www.pulsehospital.com', 'pulsehospital.com', '123.45.67.89']


2. DATABASE CONFIGURATION (Live MySQL)
----------------------------------------------------------
# Localhost ki jagah live database details dalein
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'live_db_name',       # Hosting panel se milega
        'USER': 'live_db_user',       # Hosting panel se milega
        'PASSWORD': 'strong_password', # Jo aapne hosting mein banaya
        'HOST': 'localhost',           # Zyadatar hosting mein localhost hi rehta hai
        'PORT': '3306',
    }
}


3. STATIC & MEDIA FILES (Design aur Images ke liye)
----------------------------------------------------------
import os

# Static files (CSS/JS) ke liye path
STATIC_URL = '/static/'
STATICFILES_DIRS = [os.path.join(BASE_DIR, 'static')]
STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles') # Command: collectstatic isi folder mein files dalega

# Media files (Patient reports/Photos) ke liye path
MEDIA_URL = '/media/'
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')
